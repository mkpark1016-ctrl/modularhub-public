# 플랜엠 2023~2025 재작성 재무제표 원천 대사

이 문서는 플랜엠 감사보고서 3개를 공개 View Model에 바로 반영하기 전, 원천별 보고값과 재작성값의 우선순위를 확정하기 위한 대사 기록이다. 첨부 PDF는 저장소에 복사하지 않았고, 결과는 내부 원천 대사 JSON에만 기록했다.

| 2024 | `planm_audit_report_2026_06_25` | 2026 보고서의 최신 재작성 비교 재무제표 | 2025 보고서의 최초 보고값 |

지시서에 포함된 3,529,782,000원은 PDF 텍스트 검색과 주석 23 표 대사에서 발견되지 않았다. 원문 표 기준 당기순이익 오류 수정 효과는 3,529,017,000원이다. 이 차이는 `planm_requested_amount_3529782000_not_found` unresolved item으로 남겼다.

## 대사 산출물

- JSON: `data/company_reports/planm/restatement_source_matrix_2023_2025.json`
- 테스트: `tests/test_planm_restatement_source_matrix.py`

JSON에는 2023, 2024, 2025 각 연도에 대해 최초 보고값, 재작성값, 최종 선택값을 구분했다. 금액은 원 단위 정수로 저장했다. 본문 표에서 확인하지 못했거나 해당 항목이 없는 값은 0으로 대체하지 않고 `not_disclosed`, `not_applicable`, 또는 `pending_manual_page_check` 상태로 남겼다.

## 공개 반영 상태

이번 단계는 원천 대사만 수행한다.

- `frontend/public/data/companies/company_report_insights.json` 변경 없음
- `frontend/public/data/companies/companies.json` 변경 없음
- `frontend/public/data/companies/company_intelligence_v2.json` 변경 없음
- `frontend/public/data/news.json` 변경 없음
- `frontend/public/data/business.json` 변경 없음
- UI 변경 없음

2023년 `total_equity`는 2025-04-24 보고서의 first-restated 금액을 보존하되 공개 적용 대상으로 표시하지 않았다. 2026-06-25 보고서 주석 23의 2024년초 추가 기초 조정 777,851천원이 2023년말 최종 자본총계에 직접 반영되어야 하는지 독립 원문 표로 확인하기 전까지 `public_application_eligible: false`, `restatement_completeness: partial` 상태를 유지한다.

## 남은 확인 항목

- 2024-04-15 보고서의 독립감사인 감사보고일은 제출일과 별도로 확인하지 못해 `pending_manual_page_check`로 보존했다.
- 2025-04-24 보고서 감사인 책임 문단의 회계기준 표현은 공개 적용 전 원문 재확인이 필요하다.
- 일부 재작성 현금흐름 항목은 주석의 천원 단위 표에서 확인되어 원 단위로 환산했다.
- 2026-06-25 보고서 주석 23의 2023년 추가 기초 조정 효과는 아직 공개 View Model 자동 적용 대상이 아니다.
