# 유창이앤씨 기업 재무 View Model 차이 감사

## 범위

이 문서는 기존 공개 기업정보(`frontend/public/data/companies/companies.json`)의 유창이앤씨 재무값과 감사보고서 기반 View Model(`frontend/public/data/companies/company_report_insights.json`)의 차이를 기록한다.

이번 단계에서는 기존 공개 기업정보 값을 자동 수정하지 않는다.

## 차이 발생 원인 후보

- 기존 공개 기업정보 값은 수동 검증 baseline에서 표시용 또는 정리용으로 반올림된 값일 가능성이 높다.
- 감사보고서 기반 View Model은 원 단위 reported 값을 기준으로 하므로 반올림 잔차가 드러난다.
- 기존 공개 기업정보에는 순이익, 현금흐름, 차입금, 매출채권 합계 등 이번 View Model의 전체 항목이 모두 포함되어 있지 않다.

## 기존 화면 수정이 필요한 필드

후속 UI 단계에서 기업정보 재무 탭이 감사보고서 기준 원 단위 View Model을 사용한다면 다음 필드를 우선 전환 대상으로 본다.

- 매출액
- 매출총이익
- 영업이익
- 영업이익률
- 매출총이익률
- 영업현금흐름
- 총차입금
- 매출채권 합계

## 유지해야 할 필드

기존 기업정보의 회사 개요, 생산시설, 프로젝트, 기술·특허, 출처 구조는 이번 View Model 생성과 별개로 유지한다.

## UI 단계 권고

- 기업 상세 재무 탭에서는 원 단위 `raw_krw`를 계산 기준으로 사용한다.
- 화면에는 `display_text`를 표시한다.
- 제품매출과 공사매출은 모듈러 매출로 표시하지 않는다.
- 유창엠앤씨 등 관계사 실적을 유창이앤씨 별도 실적으로 합산하지 않는 경고를 유지한다.
- `source_locations.section`은 인코딩에 안전한 표준 코드로 저장하고, 한국어 표시명은 후속 UI에서 코드 매핑으로 제공한다.
- `pending_manual_page_check`가 남은 주석 기반 수치는 출처 상세에서 수동 페이지 확인 필요로 표시한다. 이 상태는 페이지 미확인 상태이지 section 미확인 상태가 아니다.
